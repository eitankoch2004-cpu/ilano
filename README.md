# ILANO — המנהל הרפואי של הבית

מסמך נכנס. פעולה יוצאת.

**האפליקציה החיה:** [eitankoch2004-cpu.github.io/ilano/app/](https://eitankoch2004-cpu.github.io/ilano/app/)

---

## מה זה

ILANO מלווה את הבריאות של כל בני המשפחה — ובמיוחד ברגעי המעבר
שבהם הטיפול מתחלף ומידע נופל.

**כל אמירה מצטטת מקור.** אין אבחון ואין ייעוץ רפואי.
ILANO מציעה — האדם מאשר.

---

## המבנה

```
app/
├── index.html      ← האפליקציה
├── manifest.json   ← הגדרות PWA
├── sw.js           ← עבודה אופליין
├── db/             ← ספריית Supabase
└── icons/          ← אייקוני מסך הבית
```

## הסטאק

HTML + CSS + JavaScript גולמי. **אפס ספריות build.**
בסיס נתונים: Supabase — Postgres עם Row Level Security.

## שני הכללים שבנויים לתוך בסיס הנתונים

1. **כל פעולה חייבת מקור.** העמודה `source_text` היא `not null`,
   ויש כלל שדוחה מקור ריק. פעולה בלי מקור לא נשמרת.

2. **אין גישה בלי אישור.** אין ברירת מחדל של "רואה". בלי שורה
   בטבלת `consents` — בסיס הנתונים לא מחזיר את בן הבית.

⚠️ אין חיבור לאף קופת חולים. הקופה נרשמת כדי לדעת לאן לפנות,
לא כדי למשוך משם מידע.
